## 九、文本与样式

| 效果/符号                    | 意义                           | 命令                    | 示例代码                       |
| ------------------------ | ---------------------------- | --------------------- | -------------------------- |
| $\text{such that } x>0$  | 在数学公式中插入**普通文本**             | `\text{...}`          | `$\text{such that } x>0$`  |
| $\operatorname{span}(S)$ | 定义**正体算子名称**                 | `\operatorname{...}`  | `$\operatorname{span}(S)$` |
| $\mathbf{A}$             | 将字母或数字设为**粗体**（罗马体）          | `\mathbf{x}`          | `$\mathbf{A}$`             |
| $\boldsymbol{\alpha}$    | 将**希腊字母**或符号设为粗体             | `\boldsymbol{\alpha}` | `$\boldsymbol{\alpha}$`    |
| $\mathrm{e}^{x}$         | 将内容设为**罗马体（正体）**，常用于微分符号、单位等 | `\mathrm{...}`        | `$\mathrm{e}^{x}$`         |
| $\mathbb{R}$             | **黑板粗体**（双线体），通常表示数集         | `\mathbb{R}`          | `$\mathbb{R}$`             |
| $\mathcal{L}$            | **花体/手写体**（书法体）              | `\mathcal{L}`         | `$\mathcal{L}$`            |
| $\mathfrak{g}$           | **哥特体**（Fraktur 字体）          | `\mathfrak{g}`        | `$\mathfrak{g}$`           |

---

**提示**：在 **Obsidian** 中，所有命令必须在 `$...$`（行内）或 `$$...$$`（块级）内使用。若某些符号不显示，请检查是否启用了 `MathJax`（**Obsidian** 默认支持）。
