# 二次曲面的标准形化简与分类

## 光滑曲面的定义

$S \subset \mathbb{R}^3$ 称为光滑曲面，若对任意 $P \in S$，存在开集 $V \subset \mathbb{R}^3$ 使得 $S \cap V$ 是某个开集 $U \subset \mathbb{R}^2$ 到 $\mathbb{R}^3$ 的光滑嵌入的像（即光滑参数化）。二次方程给出的集合可能退化（如点、空集、直线、平面等），此时不满足光滑曲面的定义。

## 化简原理

给定矩阵 $A \in \operatorname{Mat}_{3\times3}(\mathbb{R})$，考虑方程  

$$
x^{\mathsf{T}} A x + 2 b^{\mathsf{T}} x + c = 0,\qquad x \in \mathbb{R}^3.
$$

解集 $S \subset \mathbb{R}^3$ 的形状在**平移**和**正交变换**（等距）下不变，因此可借助这些变换化简方程。

## 化简 $A$

因为 $A = \frac{1}{2}(A + A^{\mathsf{T}}) + \frac{1}{2}(A - A^{\mathsf{T}})$，而 $x^{\mathsf{T}}(A - A^{\mathsf{T}})x = 0$，故可设 $A = A^{\mathsf{T}}$。再对 $x$ 做正交变换 $x = P\tilde{x}$（$P \in O(3,\mathbb{R})$），使 $PAP^{\mathsf{T}} = \operatorname{diag}\{\lambda_1,\lambda_2,\lambda_3\}$。于是方程化为  

$$
\lambda_1 \tilde{x}_1^2 + \lambda_2 \tilde{x}_2^2 + \lambda_3 \tilde{x}_3^2 + 2\tilde{b}_1 \tilde{x}_1 + 2\tilde{b}_2 \tilde{x}_2 + 2\tilde{b}_3 \tilde{x}_3 + c = 0.
$$

## 分类讨论

### 一、$\lambda_1,\lambda_2,\lambda_3$ 均非零

对每个变量配方：  

$$
\lambda_i\left(\tilde{x}_i + \frac{\tilde{b}_i}{\lambda_i}\right)^2 - \frac{\tilde{b}_i^2}{\lambda_i},\quad i=1,2,3.
$$

令 $x_i' = \tilde{x}_i + \frac{\tilde{b}_i}{\lambda_i}$，则方程化为  

$$
\lambda_1 x_1'^2 + \lambda_2 x_2'^2 + \lambda_3 x_3'^2 + C = 0,
$$

其中 $C = c - \sum_{i=1}^3 \frac{\tilde{b}_i^2}{\lambda_i}$。

#### 1.1 椭球面  
$\lambda_1,\lambda_2,\lambda_3 > 0,\ C < 0$。非退化，光滑曲面。

#### 1.2 退化为一点  
$\lambda_1,\lambda_2,\lambda_3 > 0,\ C = 0$，解仅为原点。退化，不是光滑曲面。

#### 1.3 空集  
$\lambda_1,\lambda_2,\lambda_3 > 0,\ C > 0$，无实点。
#### 1.4 单叶双曲面  
$\lambda_1,\lambda_2 > 0,\ \lambda_3 < 0,\ C < 0$（标准形 $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$）。非退化，光滑曲面。

#### 1.5 双叶双曲面  
$\lambda_1,\lambda_2 > 0,\ \lambda_3 < 0,\ C > 0$。非退化，光滑曲面。

#### 1.6 二次锥面  
$\lambda_1,\lambda_2 > 0,\ \lambda_3 < 0,\ C = 0$。除原点外光滑，但原点处不可微，**不是光滑曲面**。

>其他情况等式两侧同乘 $-1$ 即可得到。

---

### 二、$\lambda_1,\lambda_2 \neq 0,\ \lambda_3 = 0$

方程化为  

$$
\lambda_1 \tilde{x}_1^2 + \lambda_2 \tilde{x}_2^2 + 2\tilde{b}_1 \tilde{x}_1 + 2\tilde{b}_2 \tilde{x}_2 + 2\tilde{b}_3 \tilde{x}_3 + c = 0.
$$

#### 2.1 $\tilde{b}_3 \neq 0$

对 $x_1,x_2$ 配方，令 $x_i' = \tilde{x}_i + \frac{\tilde{b}_i}{\lambda_i}\ (i=1,2)$，则  

$$
\lambda_1 x_1'^2 + \lambda_2 x_2'^2 + 2\tilde{b}_3 \tilde{x}_3 + c' = 0,
$$

其中 $c' = c - \frac{\tilde{b}_1^2}{\lambda_1} - \frac{\tilde{b}_2^2}{\lambda_2}$。再令 $x_3' = \tilde{x}_3 + \frac{c'}{2\tilde{b}_3}$，得  

$$
\lambda_1 x_1'^2 + \lambda_2 x_2'^2 + 2\tilde{b}_3 x_3' = 0.
$$

##### 2.1.1 椭圆抛物面  
$\lambda_1,\lambda_2$ 同号。光滑曲面。

##### 2.1.2 双曲抛物面（马鞍面）  
$\lambda_1,\lambda_2$ 异号。光滑曲面。

#### 2.2 $\tilde{b}_3 = 0$

方程退化为  

$$
\lambda_1 x_1'^2 + \lambda_2 x_2'^2 + C = 0,
$$

其中 $C = c - \frac{\tilde{b}_1^2}{\lambda_1} - \frac{\tilde{b}_2^2}{\lambda_2}$，$x_3$ 自由。

##### 2.2.1 椭圆柱面  
$\lambda_1,\lambda_2 > 0,\ C < 0$ 。光滑曲面。

##### 2.2.2 一条直线  
$\lambda_1,\lambda_2 > 0,\ C = 0$ 。解为 $x_1' = 0,\ x_2' = 0$，$x_3$ 自由。退化，不是光滑曲面。

##### 2.2.3 空集  
$\lambda_1,\lambda_2 > 0,\ C > 0$ 。

##### 2.2.4 双曲柱面  
$\lambda_1 > 0,\ \lambda_2 < 0,\ C \neq 0$。光滑曲面。

##### 2.2.5 一对相交平面  
$\lambda_1 > 0,\ \lambda_2 < 0,\ C = 0$。在交线处不可微，**不是光滑曲面**。


---

### 三、$\lambda_1 \neq 0,\ \lambda_2 = \lambda_3 = 0$

方程化为  

$$
\lambda_1 \tilde{x}_1^2 + 2\tilde{b}_1 \tilde{x}_1 + 2\tilde{b}_2 \tilde{x}_2 + 2\tilde{b}_3 \tilde{x}_3 + c = 0.
$$

#### 3.1 $\tilde{b}_2,\tilde{b}_3$ 不全为零

对 $x_1$ 配方：  

$$
\lambda_1\left(\tilde{x}_1 + \frac{\tilde{b}_1}{\lambda_1}\right)^2 + 2\tilde{b}_2 \tilde{x}_2 + 2\tilde{b}_3 \tilde{x}_3 + c' = 0,
$$

其中 $c' = c - \frac{\tilde{b}_1^2}{\lambda_1}$。通过旋转 $x_2,x_3$ 平面，将 $2\tilde{b}_2 \tilde{x}_2 + 2\tilde{b}_3 \tilde{x}_3$ 化为 $2b\, y$，再平移 $y$ 消去常数，得  

$$
\lambda_1 x_1'^2 + 2b\, y = 0.
$$

这是**抛物柱面**。光滑曲面。

#### 3.2 $\tilde{b}_2 = \tilde{b}_3 = 0$

方程为  

$$
\lambda_1 x_1'^2 + C = 0,
$$

其中 $x_1' = \tilde{x}_1 + \frac{\tilde{b}_1}{\lambda_1}$，$C = c - \frac{\tilde{b}_1^2}{\lambda_1}$，$x_2,x_3$ 自由。

##### 3.2.1 一对平行平面  
$\lambda_1 ,C$ 异号，解为 $x_1' = \pm \sqrt{-C/\lambda_1}$。每个平面都是光滑曲面（整体不连通但局部光滑）。

##### 3.2.2 一个平面  
$C = 0$，解为 $x_1' = 0$。光滑曲面。

##### 3.2.3 空集  
$\lambda_1,C > 0$ 同号。

---

## 总结：光滑曲面与退化情形

| 类型 | 标准形 | 条件 | 光滑性 |
|------|--------|------|--------|
| 椭球面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ | 全正，常数<0 | 光滑 |
| 单叶双曲面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$ | 两正一负 | 光滑 |
| 双叶双曲面 | $\frac{x^2}{a^2}-\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$ | 一正两负 | 光滑 |
| 椭圆抛物面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}=z$ | 同号，有线性项 | 光滑 |
| 双曲抛物面 | $\frac{x^2}{a^2}-\frac{y^2}{b^2}=z$ | 异号，有线性项 | 光滑 |
| 椭圆柱面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ | 同号，常数<0，无z线性 | 光滑 |
| 双曲柱面 | $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$ | 异号，常数≠0 | 光滑 |
| 抛物柱面 | $x^2 = 2py$ | 秩1，有线性项 | 光滑 |
| 平面（单或平行） | $x = \text{const}$ | 退化 | 光滑（单个平面） |
| 二次锥面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=0$ | 常数=0，特征值异号 | **非光滑**（顶点奇点） |
| 相交平面 | $x^2 - y^2 = 0$ | 秩2，常数=0，异号 | **非光滑**（交线） |
| 直线 | $x=y=0$ | 退化 | 不是曲面 |
| 点 | $x=y=z=0$ | 退化 | 不是曲面 |
| 空集 | 无实点 | — | — |

> 注：光滑曲面要求每点存在光滑参数化。上述“光滑”列中，除单个平面外，柱面、抛物面等均光滑。两个平行平面整体不连通但每个分支光滑。相交平面和锥面有奇点，故不满足定义。
