# 一、求导公式
## 一、基本初等函数的导数公式

1. **常数函数**  
   $$(C)' = 0 \quad (C\text{为常数})$$

2. **幂函数**  
   $$(x^\mu)' = \mu x^{\mu-1} \quad (\mu \in \mathbb{R})$$

3. **指数函数**  
   $$(a^x)' = a^x \ln a \quad (a>0, a\neq 1)$$  
   特例：$$(e^x)' = e^x$$

4. **对数函数**  
   $$(\log_a x)' = \frac{1}{x\ln a} \quad (a>0, a\neq 1)$$  
   特例：$$(\ln x)' = \frac{1}{x}$$

5. **三角函数**  
   - $(\sin x)' = \cos x$
   - $(\cos x)' = -\sin x$
   - $(\tan x)' = \sec^2 x$
   - $(\cot x)' = -\csc^2 x$
   - $(\sec x)' = \sec x \tan x$
   - $(\csc x)' = -\csc x \cot x$

6. **反三角函数**  
   - $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}$
   - $(\arccos x)' = -\dfrac{1}{\sqrt{1-x^2}}$
   - $(\arctan x)' = \dfrac{1}{1+x^2}$
   - $\operatorname{arccot} x)' = -\dfrac{1}{1+x^2}$
   - $(\operatorname{arcsec} x)' = \dfrac{1}{|x|\sqrt{x^2-1}}$
   - $(\operatorname{arccsc} x)' = -\dfrac{1}{|x|\sqrt{x^2-1}}$

7. **双曲函数（常用补充）**  
   - $(\sinh x)' = \cosh x$
   - $(\cosh x)' = \sinh x$
   - $(\tanh x)' = \operatorname{sech}^2 x$
   - $(\coth x)' = -\operatorname{csch}^2 x$

---

## 二、导数的四则运算法则

设 $u=u(x)$，$v=v(x)$ 可导，$C$ 为常数，则

- **线性运算**  
  $(u \pm v)' = u' \pm v'$  
  $(Cu)' = C u'$

- **乘法**  
  $(uv)' = u'v + uv'$

- **除法**  
  $\left( \dfrac{u}{v} \right)' = \dfrac{u'v - uv'}{v^2} \quad (v \neq 0)$

---

## 三、复合函数求导（链式法则）

若 $y = f(u)$，$u = g(x)$，且两函数均可导，则复合函数 $y = f(g(x))$ 的导数为  
$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = f'(u) \cdot g'(x)$$  
或写作  
$$\bigl[f(g(x))\bigr]' = f'(g(x)) \cdot g'(x)$$

---

## 四、其他常见求导法则

1. **反函数求导法则**  
   设 $y = f(x)$ 的反函数为 $x = \varphi(y)$，且 $f'(x) \neq 0$，则  
   $$\frac{dx}{dy} = \frac{1}{\frac{dy}{dx}} \quad \text{或} \quad \varphi'(y) = \frac{1}{f'(x)}$$

2. **参数方程求导**  
   若 $\begin{cases} x = \varphi(t) \\ y = \psi(t) \end{cases}$，且 $\varphi'(t) \neq 0$，则  
   $$\frac{dy}{dx} = \frac{\psi'(t)}{\varphi'(t)}$$

3. **隐函数求导**  
   由方程 $F(x,y) = 0$ 确定的函数 $y = y(x)$，在 $F_y \neq 0$ 时有  
   $$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

4. **对数求导法**  
   对形如 $y = u(x)^{v(x)}$ 的幂指函数或连乘除的复杂函数，可以先取对数再求导：  
   $$\ln |y| = v(x)\ln |u(x)| \quad \Rightarrow \quad \frac{y'}{y} = v'\ln|u| + v\cdot\frac{u'}{u}$$  
   于是 $y' = y\left( v'\ln|u| + \dfrac{vu'}{u} \right)$。

# 二、积分公式

## 一、基本不定积分公式（$C$ 为积分常数）

1. **常数与幂函数**  
   $$\int k \,dx = kx + C$$  
   $$\int x^\mu \,dx = \frac{x^{\mu+1}}{\mu+1} + C \quad (\mu \neq -1)$$  
   $$\int \frac{1}{x} \,dx = \ln |x| + C$$

2. **指数函数**  

   $$\int a^x \,dx = \frac{a^x}{\ln a} + C \quad (a>0, a\neq 1)$$  
   $$\int e^x \,dx = e^x + C$$

3. **三角函数**  
   - $\int \sin x \,dx = -\cos x + C$  
   - $\int \cos x \,dx = \sin x + C$  
   - $\int \sec^2 x \,dx = \tan x + C$  
   - $\int \csc^2 x \,dx = -\cot x + C$  
   - $\int \sec x \tan x \,dx = \sec x + C$  
   - $\int \csc x \cot x \,dx = -\csc x + C$  

   补充常用三角积分：  
   - $\int \tan x \,dx = -\ln|\cos x| + C$  
   - $\int \cot x \,dx = \ln|\sin x| + C$  
   - $\int \sec x \,dx = \ln|\sec x + \tan x| + C$  
   - $\int \csc x \,dx = \ln|\csc x - \cot x| + C$

4. **反三角函数与有理函数**  
   $$\int \frac{1}{1+x^2} \,dx = \arctan x + C$$  
   $$\int \frac{1}{\sqrt{1-x^2}} \,dx = \arcsin x + C$$

   推广形式（$a>0$）：  
   - $\displaystyle\int \frac{1}{a^2+x^2} \,dx = \frac{1}{a}\arctan \frac{x}{a} + C$  
   - $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}} \,dx = \arcsin \frac{x}{a} + C$  
   - $\displaystyle\int \frac{1}{x^2-a^2} \,dx = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$  
   - $\displaystyle\int \frac{1}{\sqrt{x^2 \pm a^2}} \,dx = \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C$

5. **双曲函数（补充）**  
   - $\int \sinh x \,dx = \cosh x + C$  
   - $\int \cosh x \,dx = \sinh x + C$  
   - $\int \tanh x \,dx = \ln|\cosh x| + C$

---

## 二、常用积分方法

1. **第一类换元法（凑微分）**  
   若 $\int f(u)\,du = F(u) + C$，则  
   $$\int f[\varphi(x)]\varphi'(x)\,dx = F[\varphi(x)] + C$$

2. **第二类换元法**  
   设 $x = \psi(t)$ 单调可导，且 $\psi'(t)\neq 0$，则  
   $$\int f(x)\,dx = \int f[\psi(t)]\psi'(t)\,dt$$  
   计算后用 $t = \psi^{-1}(x)$ 回代。

   常用三角代换：  
   - 含 $\sqrt{a^2-x^2}$，令 $x = a\sin t$  
   - 含 $\sqrt{a^2+x^2}$，令 $x = a\tan t$  
   - 含 $\sqrt{x^2-a^2}$，令 $x = a\sec t$

3. **分部积分法**  
   $$\int u\,dv = uv - \int v\,du$$  
   或写成：  
   $$\int u(x)v'(x)\,dx = u(x)v(x) - \int u'(x)v(x)\,dx$$

---

## 三、定积分常用公式

1. **牛顿-莱布尼茨公式**  
   若 $F'(x) = f(x)$，则  
   $$\int_a^b f(x)\,dx = F(b) - F(a)$$

2. **对称区间上的奇偶函数积分**  
   设 $f(x)$ 在 $[-a, a]$ 上连续，则  
   - $f$ 为偶函数时，$\displaystyle\int_{-a}^a f(x)\,dx = 2\int_0^a f(x)\,dx$  
   - $f$ 为奇函数时，$\displaystyle\int_{-a}^a f(x)\,dx = 0$
